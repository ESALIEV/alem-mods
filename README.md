# Мастерская модов Alem Colony

Игра читает отсюда список модов: https://raw.githubusercontent.com/ESALIEV/alem-mods/main/catalog.json

## Как моддеры выкладывают моды
Заявкой (Pull Request): **mods → Add file → Upload files → Propose changes → Create pull request**.
Бот (`review_pr.py`, `.github/workflows/review.yml`) проверяет заявку: только файлы мода, подделки,
антивирус, нейросеть по картинкам, mod.json, версия, автор.
- обновление своего мода и всё чисто — **принимается само**;
- новый мод, чужой мод или подозрительная картинка — метка **needs-review**, решает автор игры (Merge / Close);
- ошибки — метка **rejected**, моддер исправляет.

Кто автор какого мода — в `owners.json` (`"id мода": "логин GitHub"`). Заполняется сам, когда автор игры
принимает первую заявку мода. Можно поправить руками.

## Как добавить мод (автору игры)
1. Проверьте мод сами (поставьте в игре, поиграйте).
2. Загрузите архив в папку `mods/` (Add file → Upload files). Лучше без пробелов в имени: `tacz_arms.zip`.
3. Всё. Через 1–2 минуты GitHub сам обновит `catalog.json` и картинки (вкладка **Actions** — там видно, как идёт).

Обновить мод — загрузите новый архив с тем же именем поверх старого.
Убрать мод — удалите архив из `mods/`, запись и картинки уберутся сами.

Руками в `catalog.json` можно дописать только своё:
| поле | что значит |
|---|---|
| `rating` | ваши звёзды 1–5 (0 — без звёзд) |
| `featured` | `true` — «Выбор автора», мод первым в списке |

## Для моддеров: что положить в мод
Мастерская берёт всё из вашего `mod.json` и картинок в корне мода.

```json
{
  "id": "tacz_arms",
  "name": "TACZ Arms",
  "author": "Beluga",
  "version": "3.21",
  "desc": "Описание на русском.",

  "nameEn": "TACZ Arms",
  "descEn": "Description in English.",
  "category": "weapons",
  "minGame": "0.25.04",
  "changelog": "Что нового в этой версии.",
  "changelogEn": "What's new in this version.",
  "requires": ["other_mod_id"]
}
```
Обязательные: `id`, `name`, `version`. Остальное по желанию.

**Версию поднимайте при каждом обновлении** — по ней у игроков появляется кнопка «Обновить».

**category** — одна из: `weapons` (оружие), `buildings` (постройки), `animals` (звери),
`enemies` (враги), `events` (события), `apparel` (одежда), `items` (вещи и еда), `people` (люди),
`world` (мир), `tech` (технологии), `magic` (магия), `scripts` (скрипты), `other` (прочее).
Не указали — определится сама по файлам мода.

**Картинки** — в корень мода:
- `preview.png` — главная, лучше 16:9 (например 960×540);
- `preview1.png`, `preview2.png`, `preview3.png` — ещё скриншоты для галереи;
- каждая не больше 4 МБ.

# Мастерская модов Alem Colony

Игра читает отсюда список модов: https://raw.githubusercontent.com/ESALIEV/alem-mods/main/catalog.json

## Как добавить мод
1. Проверьте мод сами (поставьте в игре, поиграйте).
2. Положите архив в папку `mods/` (имя любое, например `more_guns.zip`).
3. Выполните: `python add_mod.py mods/more_guns.zip`
4. Если нужно, допишите в catalog.json `nameEn`, `descEn` и `minGame` (минимальная версия игры, например `0.25.04`).
5. Залейте изменения на GitHub. Игроки увидят мод после «ОБНОВИТЬ СПИСОК».

## Как обновить мод
Поднимите `version` в mod.json мода, замените архив и снова выполните шаг 3. У игроков появится кнопка «ОБНОВИТЬ».
